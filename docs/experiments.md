# 実験の記録

サイトを変えたら、ここに1行足す。毎週月曜の振り返りで、判断日が来たものを確かめて「結果」を埋める。

- 数字は `analytics` ブランチの `reports/latest.md`（毎朝 7:23 更新）と `reports/YYYY-MM-DD.json` を見る。
- 外からの訪問はまだ1日数人なので、1〜2件の差で結論を出さない。足りなければ判断日を延ばす。
- 自分たちのアクセスは 2026-11-22 から除外済み（それより前の Direct には確認の訪問が混ざっている）。
- GA4 のイベントの中身（page_type・vod_provider など）で分けて見るには、GA4 でカスタムディメンションの登録が必要（未登録。オーナーの操作が要る）。それまではイベントの回数で見る。
